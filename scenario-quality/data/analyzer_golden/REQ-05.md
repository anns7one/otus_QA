# REQ-05 - Фильтр каталога товаров

Над списком товаров расположены поля «Цена от» и «Цена до», список категорий и выпадающий список сортировки.

- **Цена от, Цена до.** Необязательные поля, принимают числа.
- **Категории.** Можно выбрать несколько категорий.
- **Сортировка.** Варианты: сначала дешёвые, сначала дорогие, по популярности.

## Поведение

- Результаты обновляются мгновенно после изменения любого фильтра.
- Показываются только товары, подходящие под все выбранные условия.
- Кнопка «Сбросить» возвращает все фильтры в исходное состояние.
