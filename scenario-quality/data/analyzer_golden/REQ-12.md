# REQ-12 - Поиск по сайту

В шапке сайта расположены поле «Поиск» и кнопка с иконкой лупы.

- **Поиск.** Необязательное поле, до 200 символов. Запрос передаётся в базу данных только как параметр, поэтому SQL-инъекции не выполняются. Введённый текст выводится на странице результатов экранированным, HTML-теги и скрипты не выполняются.

## Поведение

- Поиск запускается по нажатию Enter или кнопки с лупой.
- Результаты показываются по релевантности, по 20 на странице.
- Если ничего не найдено, появляется текст «По вашему запросу ничего не найдено».
- При пустом запросе показываются популярные товары или ничего не происходит.
