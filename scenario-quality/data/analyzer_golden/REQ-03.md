# REQ-03 - Восстановление пароля

Форма содержит поле E-mail и кнопку «Восстановить».

- **E-mail.** Обязательно для заполнения.
- **Восстановить.** Отправляет на указанный адрес письмо со ссылкой для смены пароля.

## Поведение

- Ссылка из письма действует 24 часа.
- По ссылке открывается форма ввода нового пароля.
- Новый пароль должен соответствовать тем же требованиям, что и при регистрации.
- Ссылка становится недействительной через 1 час после отправки письма.
- После смены пароля пользователь перенаправляется на удобную страницу.
