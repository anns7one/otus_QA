# Бизнес-требования: страница каталога курсов (направление «Программирование»)

**Объект:** https://otus.ru/catalog/courses?categories=programming
**Версия:** 1.0
**Статус:** учебный документ, требования составлены самостоятельно в рамках ДЗ

Требования сформулированы с измеримыми критериями приёмки — иначе по ним
нельзя написать проверяемые тест-кейсы.

---

## BR-001. Открытие каталога по прямой ссылке

Пользователь должен попадать на отфильтрованный каталог по прямой ссылке с
параметром направления, без дополнительных действий.

**Критерии приёмки:**
- Переход по `?categories=programming` открывает каталог за ≤ 3 сек
- В фильтре «Направление» отмечено значение «Программирование»
- В каталоге отображается не менее 1 карточки курса
- В консоли браузера нет ошибок уровня error

---

## BR-002. Фильтрация по направлению

Каталог показывает только курсы выбранного направления.

**Критерии приёмки:**
- При активном фильтре «Программирование» все карточки **в блоке каталога**
  относятся к этому направлению
- Блок «Вам также может быть интересно» — рекомендации, на него фильтр
  **не распространяется**, и он визуально отделён от результатов каталога
- Смена направления обновляет список без перезагрузки страницы
- Выбранное направление отражается в адресной строке

---

## BR-003. Догрузка результатов

Каталог не выгружает весь список сразу — пользователь догружает его по запросу.

**Критерии приёмки:**
- При первой загрузке отображается 10 карточек
- Кнопка «Показать еще 20» видна, если доступны ещё курсы
- Нажатие догружает следующую порцию без перезагрузки страницы
- Ранее показанные карточки не исчезают и не дублируются
- Когда курсы закончились, кнопка скрывается

---

## BR-004. Сброс фильтров

Пользователь может вернуть каталог в исходное состояние одним действием.

**Критерии приёмки:**
- Кнопка «Очистить фильтры» доступна, когда применён хотя бы один фильтр
- Нажатие возвращает все фильтры к значениям по умолчанию
  («Все направления», «Любой уровень», «Все типы», 0–15 месяцев)
- Параметры фильтрации удаляются из адресной строки
- Список курсов обновляется в соответствии со сброшенными фильтрами

---

## BR-005. Содержимое карточки курса

Карточка даёт достаточно данных для выбора без перехода на страницу курса.

**Критерии приёмки:**
- Каждая карточка содержит: тип («Курс» или «Специализация»), название,
  дату старта, продолжительность
- Формат даты и длительности: `30 июня, 2026 · 3 месяца`
- Бейдж («Успеть!», «Скидка N ₽») отображается при наличии, отсутствие бейджа
  не ломает вёрстку карточки
- Клик по карточке ведёт на страницу соответствующего курса

---

## BR-006. Комбинация фильтров

Фильтры применяются совместно, а не заменяют друг друга.

**Критерии приёмки:**
- Одновременный выбор «Программирование» + «Basic» + «Курсы» сужает выдачу
- Если под комбинацию нет курсов, показывается пустое состояние с пояснением,
  а не пустая страница без объяснения
- Снятие одного фильтра расширяет выдачу, остальные остаются применёнными
