## TC-001. Открытие каталога по прямой ссылке

- Требование: BR-001
- Приоритет: Высокий
- Тип: позитивный
- Предусловия: Пользователь находится на странице https://otus.ru/catalog/courses

**Шаги:**
1. Пользователь нажимает прямую ссылку с параметром направления ?categories=programming.
2. Пользователь ждёт меньше 3 секунд, пока страница загрузится.
3. Пользователь видит отфильтрованный каталог с не менее 1 карточкой курса.

**Ожидаемый результат:** Страница отфильтрована и показывает не менее 1 карточку курса.

## TC-002. Фильтрация по направлению

- Требование: BR-002
- Приоритет: Средний
- Тип: позитивный
- Предусловия: Пользователь находится на странице https://otus.ru/catalog/courses с фильтром «Программирование» примененным.

**Шаги:**
1. Пользователь активирует фильтр «Программирование».
2. Пользователь ждёт, пока страница загрузится.
3. Пользователь видит только курсы выбранного направления в блоке каталога.

**Ожидаемый результат:** В блоке каталога отображается только курсов выбранного направления «Программирование».

## TC-003. Неправильная комбинация фильтров

- Требование: BR-006
- Приоритет: Низкий
- Тип: негативный
- Предусловия: Пользователь находится на странице https://otus.ru/catalog/courses с фильтрами «Программирование» и «Basic».

**Шаги:**
1. Пользователь активирует фильтр «Программирование» и «Basic».
2. Пользователь ждёт, пока страница загрузится.
3. Пользователь видит пустое состояние с пояснением, а не пустую страницу без объяснения.

**Ожидаемый результат:** Вместо выдачи курсов, пользователю показывается пустое состояние с пояснением.
