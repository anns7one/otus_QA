# Загрузка страницы
- [ ] Страница загружена и отображается правильно.
- [ ] В заголовке страницы отражено текущее состояние фильтров.
- [ ] Найдены все элементы управления (кнопки, поле поиска, ссылка на сворачивание).
- [ ] Страница не имеет ошибок и не содержит непредвиденных ошибок.

# Фильтры
- [ ] В фильтрах отображается правильный список направлений.
- [ ] Направление «Программирование» задается правильно в URL (?categories=programming).
- [ ] Уровень и тип обучения отображаются как указано.
- [ ] Продолжительность отображается как 0-15 месяцев.
- [ ] Кнопка «Очистить фильтры» работает правильно.

# Карточки курсов
- [ ] В карточках курса отображается правильный тип (курс или специализация).
- [ ] Бейджы «Успеть!» и «Скидка N ₽» отображаются как указано.
- [ ] Название курса отображается правильно.
- [ ] Дата старта и продолжительность отображаются в правильном формате (30 июня, 2026 · 3 месяца).
- [ ] Карточки курсов не содержат ошибок.

# Пагинация
- [ ] Страница пагинируется правильно.
- [ ] Кнопка «Показать еще 20» загружает карточки без перезагрузки страницы.
- [ ] В блоке «Вам также может быть интересно» отображается правильный список курсов.

# Адаптивность
- [ ] Страница адаптируется правильно для различных размеров экрана.
- [ ] Элементы управления и карточки курсов отображаются в правильном формате на разных устройствах.
