# Загрузка страницы
- [ ] Страница загружена и отображается корректно.
- [ ] В заголовке страницы отражено текущее состояние фильтров.
- [ ] На странице отсутствуют ошибки или предупреждения.

# Фильтры
- [ ] Фильтр «Направление» отображает все доступные направления.
- [ ] Фильтр «Уровень» отображает все доступные уровни.
- [ ] Фильтр «Тип обучения» отображает все доступные типы обучения.
- [ ] При изменении фильтра страница обновляется корректно.

# Карточки курсов
- [ ] Каждая карточка имеет правильный тип (Курс или Специализация).
- [ ] Каждая карточка имеет правильную бейдж (Успеть! или Скидка N ₽).
- [ ] Каждая карточка имеет правильное название.
- [ ] Каждая карточка имеет правильную дату старта и продолжительность.

# Пагинация
- [ ] При навигации по странице карточек отображается правильная pagination.
- [ ] При нажатии на «Показать еще 20» карточки обновляются корректно.
- [ ] При нажатии на «Очистить фильтры» фильтры обновляются корректно.

# Адаптивность
- [ ] Страница адаптируется правильно для различных размеров экрана.
- [ ] Блок «Вам также может быть интересно» отображается correctly и не мешает основному контенту.
- [ ] Ссылка «Свернуть» отображается correctly и работает корректно.
