# Тест-план по каталогу курсов по программированию

## Объём
- Каталог курсов по программированию.

## Вне объёма
- Содержимое карточек курса, если оно не соответствует критериям приёмки.

## Подход
- Уровни: функциональное тестирование.
- Виды тестирования: автоматизированное тестирование, ручное тестирование.

## Критерии входа
- Тестируемый каталог должен быть доступен по прямой ссылке с параметром направления.
- Тестируемый каталог должен содержать отображение фильтров и кнопки «Очистить фильтры».
- Тестируемый каталог должен содержать отображение карточек курса.

## Критерии выхода
- Каталог должен быть доступен по прямой ссылке с параметром направления.
- Каталог должен содержать отображение фильтров и кнопки «Очистить фильтры».
- Каталог должен содержать отображение карточек курса.

## Риски
| Риск | Мера снижения |
|---|---|
| Неправильная работа фильтра | Тестируемый каталог должен содержать правильную работу фильтров. |
| Неправильное отображение карточек | Тестируемый каталог должен содержать правильное отображение карточек курса. |
| Недоступность каталога | Тестируемый каталог должен быть доступен по прямой ссылке с параметром направления. |
