# Тест-план по каталогу курсов по программированию

## Объём
- Тестируемая страница каталога курсов по программированию.

## Вне объёма
- Неправильные или отсутствующие данные в фильтрах.
- Неправильная работа кнопки «Очистить фильтры».
- Неправильная работа кнопки «Показать еще 20».

## Подход
- Тестирование с использованием различных методов (например, поиск, нажатие на элементы).
- Использование различных браузеров и систем операционных систем.

## Критерии входа
- Переход на страницу каталога курсов по программированию.
- Активация фильтров (например, «Программирование», «Basic»).
- Нажатие кнопки «Показать еще 20».

## Критерии выхода
- Вывод на экран не менее 1 карточки курса.
- Правильная работа фильтров и кнопок.
- Успешный переход к следующей порции.

## Риски
| Риск | Мера снижения |
|---|---|
| Неправильные данные в фильтрах | Тестирование с использованием различных данных. |
| Неправильная работа кнопки «Очистить фильтры» | Тестирование с использованием правильной работы кнопки. |
| Неправильная работа кнопки «Показать еще 20» | Тестирование с использованием правильной работы кнопки. |

## Ресурсы
- Использование различных браузеров (например, Google Chrome, Mozilla Firefox).
- Использование различных систем операционных систем (например, Windows, macOS).
- Тестируемый с помощью тестирования.
