## Запасные планы

| Проблема | Решение |
|----------|---------|
| Ollama не отвечает | Переключиться на OpenRouter / скрины |
| Docker не стартует | Локальный `uvicorn` + готовая БД |
| Модель слишком «умная» и не ломается | Использовать меньшую модель (7B) или более агрессивные payloads |
| Модель слишком «глупая» | Увеличить temperature или сменить модель |
