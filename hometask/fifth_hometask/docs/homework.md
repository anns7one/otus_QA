# Домашнее задание (практическое)

## Тема: Тестирование безопасности промптов и защита LLM-агента

**Цель:**  
На практике найти, эксплуатировать и закрыть уязвимости промптов (Prompt Injection, Leakage, Tool Abuse, Encoding, Jailbreak, RAG Poisoning) и встроить автоматическую проверку безопасности.

Это не теория. Вы должны получить работающий код, воспроизводимые атаки и отчёт.

---

## Требования к окружению

- Python 3.11+
- Docker + docker-compose (обязательно)
- Локальная или удалённая LLM (рекомендуется Ollama + модель ≥ 7B)
- Git-репозиторий (публичный или с доступом преподавателю)

---

## Задание (строго по пунктам)

### 1. Поднять уязвимый LLM-агент (30–40 % оценки)

Создайте простой агент на Python (FastAPI или Flask + LangChain / LlamaIndex / чистый OpenAI-compatible client), который:

- Принимает пользовательский запрос (`POST /chat`).
- Имеет **системный промпт** с ролью «QA Assistant / Internal Support Bot».
- Имеет доступ минимум к **двум инструментам**:
  1. SQL-инструмент (SQLite с таблицами `clients`, `orders`, `secrets`).
  2. Файловый или HTTP/API-инструмент (чтение «внутренних» документов / RAG).
- Системный промпт **намеренно слабый**.

**Артефакты:**
- `docker-compose.yml` + Dockerfile
- Код агента
- README с командой запуска одной командой

Можно взять за основу этот репозиторий и доработать.

### 2. Провести ручной red-team (минимум 6 атак)

1. **Direct Prompt Injection**
2. **Prompt Leakage / Hidden Context Exposure**
3. **Tool Abuse**
4. **RAG Poisoning / Indirect Injection**
5. **Encoding-атака**
6. **Jailbreak / Role-play**

Для каждой атаки в отчёте:
- Точный Payload
- Ответ модели (лог или скрин)
- Почему сработало
- Какой риск из **OWASP GenAI LLM Top 10 2026**

### 3. Исправить агент (защита)

- Жёсткое **Prompt Isolation**
- **Least Privilege** для инструментов
- **Input Guard**
- **Output Guard**
- Показать, что те же 6 атак теперь не проходят

### 4. Автоматизировать тестирование безопасности

- Promptfoo **или** Garak **или** свой pytest
- Минимум **15–20 payloads**
- Отчёт pass/fail

### 5. Отчёт (`REPORT.md`)

1. Архитектура агента (до / после)
2. Список всех атак + результаты (до и после)
3. Какие меры защиты сработали против каких атак
4. Как запустить автоматические тесты
5. Ограничения решения и что добавить в production
6. Ссылки на инструменты и OWASP

## Критерии «Принято»

- [ ] Агент поднимается одной командой через Docker
- [ ] Есть работающая уязвимая и защищённая версии
- [ ] Задокументированы ≥ 6 успешных атак разных классов
- [ ] После защиты те же атаки блокируются
- [ ] Есть автоматизированный прогон (≥ 15 payloads) с отчётом
- [ ] REPORT.md заполнен
- [ ] Код можно воспроизвести у преподавателя
