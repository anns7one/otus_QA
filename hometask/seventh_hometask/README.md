# ДЗ-7. Промпт-генератор тестовой документации + оценка через Ollama

Генерирует промпты для LLM — по одному на каждый из 4
типов тестовой документации: test case, checklist, test plan, QA report.
Промпты строятся по шаблону Роль → Контекст → Техника → Формат → Ограничения
на основе требования из `requirement.md`. Качество промптов оценивается через
Ollama (LLM-судья) по 5 критериям: читаемость, контекстность, чёткость целей,
покрытие сценариев, недвусмысленность.

## Стек

Python 3, Docker, Ollama (`qwen2.5:7b`), библиотека `openai` (OpenAI-совместимый клиент к Ollama).

## Структура

- `requirement.md` — требование (форма регистрации)
- `prompt_generator.py` — строит промпты по 4 типам документов
- `evaluator.py` — прогоняет промпт через Ollama и оценивает результат LLM-судьёй
- `run.py` — точка входа: генерирует и оценивает все 4 типа, пишет результаты
- `analyze_runs.py` — считает разброс оценок между всеми накопленными прогонами
- `*_results.md` (в корне) — результаты последнего прогона
- `results/history/NN-progon/` — архив каждого прогона
- `results/stability_report.md` — таблица разброса оценок по прогонам
